# Screenshots

Place project screenshots in this folder and link them from the root `README.md`.

Suggested filenames:

| File | Caption |
|---|---|
| `cli-menu.png` | Interactive CLI menu |
| `analysis-output.png` | Code analysis report |
| `documentation-output.png` | Documentation generation |
| `testing-output.png` | Generated tests / execution summary |

Do not commit fabricated or mock screenshots.
